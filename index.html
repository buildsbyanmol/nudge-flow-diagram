Flow diagram

The same logic as a decision flow. Any SHOW box ends the session. A nudge that is skipped was never displayed, so its own counter does not move and it stays eligible for a later session.

Runs in parallel, outside this flow

The gamification secondary nudge is only the mission logo animating. It is not a popup, it does not enter this flow, and it does not use up the one-nudge-per-session slot. It starts once the primary nudge is done and runs every session until the user attempts a task for the first time, up to 5 times per session with a 5 second gap between repeats.
